# Onglets de fichiers et explorateur — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Per-workspace file tabs (pinned and temporary) with an editor, and a toggleable explorer of the workspace's space folders, in Antoine's `antoine` mod.

**Architecture:** A pure module `files.js` (Node-tested) holds the tab rules. The `antoine` mod gains two more parts, chosen by props like the menu/dialogs: `{ view: "file" }` (editor) and `{ view: "explorer" }`. A clone `antoine-tabs` of the shipped tab bar draws file tabs after a separator. The `antoine` layout wraps the terminals block in a stack with the file view, and adds a hidden explorer column. All state goes through shared key `antoine.files`.

**Tech Stack:** Herdr mods (gpui-kit JS, `herdr` module), `node:test`.

**Spec:** `docs/superpowers/specs/2026-11-01-fichiers-design.md` (read `CLAUDE.md` first)

## Global Constraints

- Everything in `~/.config/herdr-app/` (`$H`); never edit shipped mods/layouts. New clone: `antoine-tabs`.
- Shared key `antoine.files` = `{ [wsId]: { pinned: string[], open: string[], shown: string|null } }` (absolute paths). Workspace ids come from `antoine.workspaces` (`active`).
- Layout ids: stack `work-stack` with children `main` (terminals) and `file-view`; block `explorer` (hidden at start, 260 px, between `workspaces` and `sidebar`).
- Keys in `keys.json` section `layout:antoine`: `cmd-s` → `antoine.save`, `cmd-w` → `antoine-tabs.close`.
- Pick a file: `exec("osascript", ["-e", "POSIX path of (choose file)"])` (30 s limit accepted).
- Conflict copy name: `<path>.herdr-YYYYMMDD-HHMMSS`, plus a `notify` saying where.
- UI text in French with accents; colors from `theme()`.
- Done = `node --test tests/` green, `herdr-app check` passes for each touched mod, `herdr-app status` `errors: []`, tried in the app.
- Git: the project folder is a repo but `$H` is not; no commit steps (Antoine commits himself).

## Review Focus

1. A tab change not made by a click (cmd-1, space change, notification, cmd-t) while a file is shown → back to terminals.
2. Unsaved text when switching workspace or quitting → saved; if the disk changed meanwhile → conflict copy + notification, never overwrite.
3. Hot reload of the mod (saving a mod file) must not clear temporary tabs; a real Herdr start must (and show terminals).
4. Missing, >1 MiB or binary file → a message in place of the editor, no crash; a missing pinned file stays pinned.
5. cmd-w with a file shown closes the file tab (asks if modified), never a hidden terminal tab.

Items 1, 3 (rule part) and 5 (rule part) are pinned in Task 1 tests; 2 and 4 by manual checks in Task 5.

### Task 1: Pure file-tab rules

**Files:**
- Create: `$H/mods/antoine/files.js`
- Test: `tests/files.test.mjs`

**Interfaces — Produces (pure, never mutate input; `st` = the `antoine.files` value or null):**
- `tabsOf(st, ws) -> { path, pinned }[]` — pinned first (in pin order), then open.
- `openFile(st, ws, path) -> st` — adds to `open` unless already pinned or open; `shown = path`.
- `pin(st, ws, path) -> st` — adds to `pinned` (once), removes from `open`, `shown = path`.
- `unpin(st, ws, path) -> st` — removes from `pinned`; `shown = null` if it was shown.
- `closeFile(st, ws, path) -> st` — removes from `open` only (pinned tabs don't close); `shown = null` if it was shown.
- `show(st, ws, path|null) -> st`.
- `shownOf(st, ws) -> string|null`.
- `boot(st) -> st` — every workspace: `open = []`, `shown = null`.
- `dropWorkspace(st, ws) -> st`.
- `roots(spaceList: {folder, cwd}[], home) -> string[]` — per space `cwd || folder || home`, de-duplicated, in order.
- `languageOf(path) -> string` — `.md`/`.markdown` → `"markdown"`; basename `.env` or starting with `.env.` → `"bash"`; else `"text"` (Task 2 may change the names after trying them in the app; tests follow).
- `conflictPath(path, date: Date) -> string` — `${path}.herdr-YYYYMMDD-HHMMSS` (local time, zero-padded).
- `isBinary(text) -> boolean` — contains `"\u0000"`.

- [ ] **Step 1: Write the failing tests** (`node:test`, import by absolute path as in `tests/workspaces.test.mjs`):
  - `openFile adds a temporary tab and shows it`; opening it again doesn't duplicate.
  - `opening a pinned file doesn't add a temporary tab`.
  - `pin moves a temporary tab to pinned`; `tabsOf` lists pinned first.
  - `closeFile never closes a pinned tab` and clears `shown` when closing the shown one.
  - `unpin removes it and clears shown`.
  - `boot clears temporary tabs and shown, keeps pinned`.
  - `files are per workspace`: opening in `w1` leaves `tabsOf(st, "w2")` empty.
  - `roots dedupes and falls back to folder then home`: `[{cwd:"/a"},{cwd:"/a",folder:"/b"},{cwd:"",folder:"/b"},{cwd:"",folder:""}]`, home `/h` → `["/a","/b","/h"]`.
  - `languageOf`: `notes.md` → markdown, `/x/.env` and `.env.local` → bash, `a.txt` → text.
  - `conflictPath`: `new Date(2026,10,1,9,5,7)` → `/x/b.md.herdr-20261101-090507`.
  - `isBinary` true for `"a\u0000b"`, false for `"abc"`.
  - inputs untouched after each call.

- [ ] **Step 2: Run, see them fail** — `node --test tests/files.test.mjs` → FAIL (module missing).
- [ ] **Step 3: Implement `files.js`** with the exports above; no `herdr` import.
- [ ] **Step 4: Run, see them pass** — `node --test tests/` → all pass (workspaces tests too).

### Task 2: File view (editor) — `antoine` part `{ view: "file" }`

**Files:**
- Create: `$H/mods/antoine/fileview.js`, `$H/mods/antoine/filestore.js` (load/save of `antoine.files`, like `store.js`)
- Modify: `$H/mods/antoine/main.js` (choose the part from `props().view`)

**Interfaces:**
- Consumes: Task 1; `load()` from `store.js` for the active workspace id.
- Produces: `filestore.js` exports `FKEY = "antoine.files"`, `loadFiles()`, `saveFiles(next)` (writes only on change), `activeWs()` (id of the open workspace or null). The file view handles command `save` from `nextCommand()`.

- [ ] **Step 1: Write `fileview.js`.** Keeps `this.docs: Map<path, { state: EditorState, base: string|null, dirty: boolean, error: string|null }>`. On render, `path = shownOf(loadFiles(), activeWs())`; if no doc for it, load with `readTextFile` in `cx.spawn` (null → error « Fichier introuvable »; rejection → « Fichier trop gros ou illisible »; `isBinary` → « Fichier binaire »), else `EditorState.new({ language: languageOf(path), value, font_family: settings().font_family, syntax: {…from theme().ansi*…} })`, `on("change")` marks dirty. Top strip: path (dim), a dot when dirty. Body: `Editor.new(state)` or the error message centered.
- [ ] **Step 2: Saving.** `save(path)`: `writeTextFile(path, text, doc.base)`; on success `base = text`, `dirty = false`; on rejection write `conflictPath(path, new Date())` with `expected = null` and `notify({ title: "Fichier modifié ailleurs", body: "Ta version est dans <nom>", level: "warning" })`. `nextCommand()` loop: `"save"` → save the shown path if dirty.
- [ ] **Step 3: Auto-save.** In render, when `activeWs()` differs from the last seen one, save every dirty doc. `async close(cx)`: save every dirty doc (awaited; 250 ms budget).
- [ ] **Step 4: Rule for languages.** Open a `.md` and a `.env` in the app (Task 5 makes this reachable; until then `herdr-app do tab.new --mod antoine --props '{"view":"file"}'` after setting a shown path is acceptable). If a name gives no color, try `"md"`, `"sh"`, `"properties"`, `"ini"`; update `languageOf` and its test to what works, or keep `"text"`.
- [ ] **Step 5: Check** — `herdr-app check ~/.config/herdr-app/mods/antoine` → passed.

### Task 4: `antoine-tabs` — separator, file tabs, pin, close, tab watcher, boot

**Files:**
- Create (command): `$H/mods/antoine-tabs/`
- Modify: `$H/mods/antoine-tabs/main.js`, `$H/mods/antoine/dialogs.js` (delete also drops the workspace's files)

**Interfaces:**
- Consumes: Task 1 (`tabsOf`, `show`, `closeFile`, `pin`, `unpin`, `boot`, `dropWorkspace`, `shownOf`), Task 2 (`loadFiles`, `saveFiles`, `activeWs`). The clone imports them with `import … from "../antoine/files.js"`; if Herdr refuses cross-mod imports, copy `files.js` and `filestore.js` into `antoine-tabs/` and ledger it.
- Produces: command `close` (via `nextCommand()`), the `work-stack` switching.

- [ ] **Step 1: Clone** — `herdr-app do mod.clone '{"name":"tabs","as":"antoine-tabs"}'` → `{ "ok": true }`.
- [ ] **Step 2: File tabs.** After the space tabs inside `tab-scroll`: a 1×18 px `border` separator (only if the workspace has file tabs or always — always, so the pin button has a home), then one tab per `tabsOf()` entry: file name, pin icon (`mods/workspace-chrome/pin.svg`) when pinned, × when temporary (click → `closeFile`; if that doc is dirty, open `confirm` with « Fermer sans sauvegarder ? »). The shown file tab is styled like the active space tab, and the active space tab loses its active style while a file is shown. Click file tab → `show(...)` + `layout.select {stack:"work-stack", child:"file-view"}`. Click a space tab → `show(st, ws, null)` + select `main` (in addition to its normal action). Right-click a pinned tab → popup with « Désépingler ». After the tabs, a pin button (`pin.svg`, title-less) → osascript pick → `pin(...)` + show it; empty output (cancel/timeout) does nothing.
- [ ] **Step 3: Back to terminals without a click.** In render: key = `${focused()?.tab}|${activeWs()}`; when it differs from the last key and a file is shown, `show(st, ws, null)` and select `main`. Clicks on space tabs set the key before running, so they don't double-trigger.
- [ ] **Step 4: `close` command.** `nextCommand()` loop: `"close"` → if a file is shown and temporary, close it (confirm if dirty — dirty state: shared `antoine.files.dirty` is not stored; ask the file view by reading a shared flag `antoine.dirty` = array of dirty paths that `fileview.js` keeps up to date (set only when the set changes)); if shown and pinned, just go back to terminals; else `run("tab.close")`.
- [ ] **Step 5: Boot.** On the first render, decide if this is a real Herdr start: run `exec("sh", ["-c", "ps -o lstart= -p $(pgrep -n herdr-app)"])`, compare with shared `antoine.boot`; if different → `saveFiles(boot(loadFiles()))`, select `main`, `setShared("antoine.boot", value)`. Ledger the choice.
- [ ] **Step 6: Workspace deletion.** In `dialogs.js` delete branch: `saveFiles(dropWorkspace(loadFiles(), ws))`.
- [ ] **Step 7: Check** — `herdr-app check` on `antoine-tabs` and `antoine` → passed.
